# Mohamed Sales Doctor AI

Mobile-friendly V1 PWA for lead diagnosis, WhatsApp message generation, and CRM row copy.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Upload this folder to GitHub, or drag/drop the project into Vercel.
2. Vercel will detect Vite automatically.
3. Build command: `npm run build`
4. Output directory: `dist`

## Install on phone

Open the deployed link on Chrome Android, then tap:
Menu → Add to Home Screen.
